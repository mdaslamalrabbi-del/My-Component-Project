# Puku Design System

Design tokens, components and usage guidance for Puku, built with Claude.

## Files

- `index.html` – the design system documentation page
- `style.css` – tokens (colors, type, spacing) and component styles, with light and dark themes
- `app.js` – interactive behavior for the documentation page

## View it

Open `index.html` in a browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from branch `main`).
