# Component source code

Ready-to-use code for the **71 Puku components** that have code, in four frameworks. Each file is the same code shown under the **Code** tab on the design system page.

| Folder | Framework | File type |
|---|---|---|
| `react/` | React / Next.js (Tailwind CSS) | `.tsx` |
| `react-native/` | React Native | `.tsx` |
| `flutter/` | Flutter | `.dart` |
| `vue/` | Vue 3 | `.vue` |

Inside each framework, components are grouped by category: `base`, `forms`, `navigation` and `data-display`.

To use one, copy its file into your app's components folder and import it. The React files use Tailwind CSS classes, so your app needs Tailwind set up.
